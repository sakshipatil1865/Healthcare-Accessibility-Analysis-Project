Local Healthcare Accessibility Analysis

A data analytics project focused on exploring publicly available information about healthcare facilities, their locations, specialties, public ratings, reviews and emergency availability.

About the Project

This project analyzes publicly listed healthcare facility information to understand facility distribution and selected service indicators across the collected local dataset.

Problem Statement

Organize healthcare facility information so users can examine facility types, locations, specialties, ratings and emergency availability in one place.

Project Objectives

Collect and clean public data, store and analyze it using SQL, perform Python-based exploratory analysis and present findings through a Power BI dashboard.

Business Relevance

The analysis demonstrates how organized healthcare data can support reporting and help identify questions for further investigation into healthcare information and appointment-management solutions.

Initial Dataset Insights

Basic observations from the collected 100-record dataset.

Facility Types

The dataset contains 50 hospitals, 25 clinics and 25 diagnostic centers.

Area Distribution

Recorded examples include Rajarampuri, Kolhapur with 9 facilities, Tarabai Park, Kolhapur with 8, and Sambhaji Nagar, Kolhapur with 5.

Service Information

Opening hours, specialties, public ratings, review counts, consultation ranges and emergency availability are included for analysis where publicly listed information was collected.

These observations describe this dataset only. They do not prove that an area has insufficient healthcare facilities or that any specific software solution is in demand.

Conclusion

The Local Healthcare Accessibility Analysis project brings together publicly listed healthcare facility information, database queries, Python analysis and Power BI visualizations. It demonstrates a structured data analytics workflow, from collecting and preparing data to presenting summaries and observations.

Further analysis using verified and more comprehensive data would be needed before drawing conclusions about actual healthcare gaps or making operational decisions.
